Overview

The first feed-forward latent 4D NVS model.

4D novel view synthesis renders a dynamic scene from viewpoints and instants that were never observed. Feed-forward methods do it with explicit 3D Gaussians plus motion, and pay with ghosting, floaters and holes.

A frozen static latent backbone supplies the 3D prior; a lightweight dynamic encoder adds a temporal residual on top. Training needs only images and binary motion masks.

Abstract

4D Novel View Synthesis (NVS) from monocular videos aims to render dynamic scenes across viewpoints and timestamps, requiring jointly inferring 3D structure and temporal dynamics. Existing feed-forward methods rely on explicit 3D Gaussian representations, which are prone to temporal inconsistency and severe rendering artifacts. We present FL4N, the first feed-forward latent 4D NVS model. We bypass explicit 3D primitives by weaving a geometrically grounded scene prior into a unified latent representation across space and time. To overcome dynamic training data scarcity, we learn a temporal residual on top of a frozen, pretrained static latent backbone. A lightweight dynamic encoder learns to isolate true scene motion from camera parallax. Trained purely on image synthesis with binary mask guidance, FL4N achieves state-of-the-art rendering quality for 4D NVS in real time. Our proposed latent representation successfully learns a strong 4D prior, generalizes across novel views and timestamps, and cleanly decouples view and time in the latent space.

Method

A temporal residual on a frozen static prior.

The pretrained static encoder and renderer stay frozen. A trainable dynamic encoder beside them only has to explain what changes over time.

1

Dynamic encoder with static anchoring

Eight transformer layers see each context frame with a learnable time token and cross-attend into the frozen static features, so they can separate camera motion from object motion.

2

Target-time residual adaptation

The residual is computed once. For a target time, interpolated time tokens drive an AdaLN time module with a zero-initialised gate, so training starts from the static prior.

3

Frozen renderer, image-only training

Static plus residual latent is decoded by the untouched renderer. Losses: L2 and perceptual on the image, extra terms on moving regions, and a mask loss. No depth, flow or 3D motion labels.

Quantitative results

State of the art performance.

Analysis

What does the residual latent actually learn?

The static model knows where to render but not when: it collapses the video into one time-invariant prediction. The residual adds the time axis, only where motion happens.
